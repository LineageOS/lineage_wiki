## Expected Peripherals

This device requires a Wi-Fi/BT peripheral device to be connected prior to flashing/booting LineageOS to function properly.

We currently support either:
* The official Banana Pi M5 [Wi-Fi/BT Combo GPIO HAT](https://docs.banana-pi.org/picture/wifibt_module1_.jpeg), information about it can be found under the "Wifi & BT support via expansion board" [here](https://docs.banana-pi.org/en/BPI-M5/BananaPi_BPI-M5).
* Most USB Realtek rtl8822cs dongles.
